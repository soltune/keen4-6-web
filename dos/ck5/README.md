# Commander Keen 5 — game data goes here

Place your own legally-owned **Commander Keen 5 (The Armageddon Machine)**
files in this directory, then run `npm run extract` from `web/`.

Required files:

| File | 内容 |
|---|---|
| `KEEN5E.EXE` | EGA executable |
| `EGAGRAPH.CK5` | graphics |
| `GAMEMAPS.CK5` | maps |
| `AUDIO.CK5` | music & sfx |
