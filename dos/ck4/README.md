# Commander Keen 4 — game data goes here

Place your own legally-owned **Commander Keen 4 (Secret of the Oracle, v1.4 recommended)**
files in this directory, then run `npm run extract` from `web/`.

Required files:

| File | 内容 |
|---|---|
| `KEEN4E.EXE` | EGA executable |
| `EGAGRAPH.CK4` | graphics |
| `GAMEMAPS.CK4` | maps |
| `AUDIO.CK4` | music & sfx |
