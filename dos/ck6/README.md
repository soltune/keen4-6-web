# Commander Keen 6 — game data goes here

Place your own legally-owned **Commander Keen 6 (Aliens Ate My Babysitter)**
files in this directory, then run `npm run extract` from `web/`.

Required files:

| File | 内容 |
|---|---|
| `Keen6.exe` | EGA executable |
| `EGAGRAPH.CK6` | graphics |
| `GAMEMAPS.CK6` | maps |
| `AUDIO.CK6` | music & sfx |
